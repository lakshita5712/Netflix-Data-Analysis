# Netflix Movies & TV Shows Data Analysis 📊

## Project Overview

This project performs Exploratory Data Analysis (EDA) on the Netflix Movies and TV Shows dataset.

The aim of this project is to analyze Netflix content trends, understand content distribution, and find insights related to genres, countries, ratings, and yearly growth.

---

## Dataset

Dataset used:
Netflix Movies and TV Shows Dataset

Source:
Kaggle

The dataset contains information about:
- Movies
- TV Shows
- Directors
- Cast
- Countries
- Release Year
- Ratings
- Genres
- Date Added

## Exploratory Data Analysis

Questions answered:

### 1. Movies vs TV Shows Distribution

Analyzed the number of Movies and TV Shows available on Netflix.


### 2. Top Content Producing Countries

Found countries contributing the highest number of Netflix titles.


### 3. Netflix Content Growth Over Years

Analyzed how Netflix content increased year by year.


### 4. Rating Distribution Analysis

Explored content availability based on audience rating categories.


### 5. Genre Analysis

Found the most popular Netflix genres/categories.


### 6. India Specific Netflix Analysis

Analyzed Indian Netflix content distribution.

---

## Key Insights

- Netflix contains more Movies compared to TV Shows.
- Content addition increased rapidly after 2015.
- International Movies and Dramas are among the most common genres.
- TV-MA is one of the most frequent audience ratings.
- Indian Netflix content mainly consists of Movies.
